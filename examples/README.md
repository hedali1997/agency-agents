# 示例

本目录包含了一些示例输出，展示了如何将 agency 的 agents 协调在一起来解决现实世界的任务。

## 为什么需要这个

agency-agents 仓库定义了数十个专业化的 agents，涵盖工程、设计、营销、产品、支持、空间计算和项目管理等领域。但仅仅定义 agents 并不能展示当你**一次性部署所有 agents**来处理单个任务时会发生什么。

这些示例回答了这个问题："**当整个 agency 一起协作时，实际效果是什么样的？**"

## 内容

### [nexus-spatial-discovery.md](./nexus-spatial-discovery.md)

**内容：** 一个完整的产品发现练习，8 个 agents 并行工作以评估一个软件机会并产生统一的计划。

**场景：** 通过网络研究识别到了 AI agent 编排和空间计算交叉领域的机会。然后同时部署整个 agency 来产出：

- 市场验证和竞争分析
- 技术架构（包含完整 SQL schema 的 8 服务系统设计）
- 品牌策略和视觉识别
- 上市和增长计划
- 客户支持运营蓝图
- 用户体验研究计划，包括人物画像和旅程地图
- 35 周项目执行计划，包含 65 个冲刺工单
- 空间界面架构规范

**使用的 Agents：**
| Agent | 角色 |
|-------|------|
| Product Trend Researcher | 市场验证、竞争格局 |
| Backend Architect | 系统架构、数据模型、API 设计 |
| Brand Guardian | 定位、视觉识别、命名 |
| Growth Hacker | 上市策略、定价、发布计划 |
| Support Responder | 支持层级、入职流程、社区 |
| UX Researcher | 人物画像、旅程地图、设计原则 |
| Project Shepherd | 阶段计划、冲刺、风险登记册 |
| XR Interface Architect | 空间 UI 规范 |

**关键要点：** 所有 8 个 agents 并行运行并产生了连贯的、相互引用的计划，无需协调开销。该输出展示了 agency 从"发现机会"到"产出完整蓝图"的单次会话能力。
